# 开头与表达

每篇确定主结构或自然叙述逻辑后再使用这些方法。按内容选少量方法，不为增加技巧而改变用户原意。

## 开头如何选

有结果先给结果，有困扰先说困扰，有观点先表达观点，有对比先展示差别，有值得好奇的事件从事件切入，有明确方法收益就说能帮什么忙。

五种可用钩子：
- 损失提醒：提示有依据的错误成本，不制造虚假焦虑。
- 数字速成：真实时间或数量加具体收益，保留适用条件，不凭空承诺翻倍。
- 熟悉话题：从与本期相关的人物、事件或季节话题切入；使用时确认事实和时效。
- 反差：突出身份、成本、前后结果或常见认知之间的真实差别。
- 好奇问题：提出正文会回答的问题，不把所有实质信息藏到最后。

不固定要求以“你是不是”开始，也不固定禁止第一人称。自己的经历足够具体且与观众相关时可以直接说。删掉长寒暄和重复预告。

## 顺序与视角调整

原稿结果出现太晚：把结果提前，补必要背景，再讲关键过程。

原稿一直讲自己、观众不知道有何关联：可按“观众处境 → 我的经历 → 变化或发现 → 做法”调整。已有相关性时不强改人称。

## 真实反转句式

| 句式 | 适用差异 |
|---|---|
| 本以为……结果…… | 预期与实际结果 |
| 大家都说……但我的经历是…… | 常见理解与个人观察；前半句也须有依据 |
| 本来想……后来才明白…… | 动机与后续反思 |
| 你可能觉得……其实…… | 直觉与有依据的新解释 |
| 表面上看……进一步看才发现…… | 表象与深入发现 |
| 为什么……？因为…… | 问题与值得解释的原因 |

反转后接具体依据或解释。不故意给错误结论，不把“更重要”改成“其他完全不重要”，没有真实反差就直接讲清楚。

## 让内容有用、有感受

- **算账**：替观众比较时间、金钱、投入、收益和适用条件。有数据才计算，没有数据就给比较维度。
- **甜头**：明确能带走的方法、清单、判断依据，也可以是陪伴和理解。正文兑现收益。
- **困难**：保留真实犹豫、痛苦、失败和调整，不卖惨、不补造低谷。
- **口语**：保留本人常用词和具体感受，长句拆短，抽象词改成动作或场景。不机械堆语气词。

## 推动行动与产品表达

- “某类人都在……”需要真实群体依据，不凭空制造从众事实。
- “只需要……就能……”只用于确实低门槛且有支撑的结果，保留必要条件。
- “如果你想……可以先……”用于连接目标与建议；只有确属必要条件时才说“一定需要”。

用户有产品或商业任务时解释产品解决什么问题，不为植入扭曲内容。没有相关任务不主动加入广告。

每篇结尾通常收束一个重点，给一个与本期相关的行动或互动建议即可。
