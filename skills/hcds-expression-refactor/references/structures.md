# 结构细则

按每篇选出的结构字母参照对应小节；这里给出每种结构的材料要求与执行要点。

## A｜问题解决型

**适合**：教观众解决一个明确问题。

**顺序**：具体困扰 → 关键原因 → 解决步骤 → 使用提醒或行动建议。

- 用具体场景写困扰，让观众认出自己的问题。
- 解释原因；与常见理解确有不同才突出反常识。
- 按操作顺序写做什么、怎么做。步骤随内容决定，不强凑三步。
- 收尾给一个可以开始的动作。

**材料门槛**：具体问题和可用办法。只有观察或原因猜想时，可改 B 探讨，不伪装为成熟教程。

## B｜观点论证型（PEEL）

**适合**：解释判断、现象，改变观众的理解。

**顺序**：Point 观点 → Evidence 依据 → Explanation 解释 → Link 连接观众。

- 先清楚表达核心判断。
- 使用真实经历、案例、已有数据或可确认引用。
- 说明依据为什么支持观点：讲完故事还不等于完成论证。
- 落回观众可以如何理解、判断或应用；有做法可补做法。

**材料门槛**：观点及支撑材料。只有主张时指出依据缺口。个人经历支持有限范围的判断，不自动证明普遍规律。

## C｜结果复盘型

**适合**：已经发生的结果、变化或发现，以及它如何发生。

**顺序**：最值得关注的结果 → 必要背景 → 关键行动、困难和转折 → 可借鉴的经验或感受。

前后差异特别关键时，也可用：过去处境 → 现在变化 → 为什么改变。

结果先行是信息优先级调整，不是机械倒叙。只保留解释结果所需的过程，不逐项汇报全部经历。

**材料门槛**：真实结果或发现，以及相关过程。失败、阶段发现、认识变化都可以作为结果；不要把相关性改成确定因果。

## D｜对比拆解型

**适合**：两个具体版本、案例或做法，其差异值得解释。

**顺序**：展示差别 → 沿同一维度展开两个案例 → 找出关键不同 → 提炼判断依据或方法。

让观众看见具体差别，避免只贴“高级”“失败”等标签。成功与失败只是对比的一种，不要求一好一坏。

**材料门槛**：两个可比较对象及细节。缺另一侧材料时不虚构陪衬，也不随意归因。

## E｜挑战记录型

**适合**：正在尝试一个目标，希望观众跟随进展。

**顺序**：目标和动机 → 本阶段行动 → 障碍及调整 → 当前进展 → 已确定的下一步。

保留失败、停滞和意外，变化不必每期都显著。

**材料门槛**：真实目标，以及行动或明确计划。尚未开始只写挑战发起，未完成只写真实进展。用户没有计划持续更新时，不替他承诺每天更新或下期内容。

## F｜经验教学型

**适合**：面向陌生观众分享一套经验、清单或方法。

**顺序**：受众痛点 → 能获得什么 → 简短相关经验 → 分点讲方法和例子 → 如何开始使用。

可信依据可以是实际尝试，不必是头衔或漂亮成绩；没有资历材料可直接进入方法。开头避免长篇铺垫，尽快交付承诺的价值。价值与分点讲述是同一主体，不必拆成多段重复表达。

**材料门槛**：有成体系的方法或经验。只有一个问题和单一做法时通常选 A 更简洁。

## G｜生活叙事型

**适合**：一件生活小事及真实状态、反应和感受。

**口播顺序**：想做什么或当时心情 → 发生什么 → 具体反应 → 留下的感受或发现。

不要求深刻感悟，不强行升华。

**材料门槛**：具体事件及个人反应。

只有用户涉及 Vlog 或要求画面建议时，使用“我—远—动—真—情”：
- 我：人物出场，交代事情或心情。
- 远：展示环境及人物与环境的关系。
- 动：展示拿、走、吃等具体动作，适合时保留现场声音。
- 真：保留即时真实反应。
- 情：用感受收尾或过渡到下一件事。

纯口播只借用叙事顺序；拍摄建议单独交付，不混入台词。
